Welcome to my new blog! This site is now built with **Angular** and **[Analog](https://analogjs.org)** — a full-stack Angular meta-framework that supports Static Site Generation (SSG).

## Why the change?

My previous blog was built with Jekyll and hosted on GitHub Pages. While Jekyll served me well for many years, I wanted to move to a more modern stack:

- **TypeScript** instead of Ruby — better tooling and type safety
- **Angular** components — reusable, composable UI
- **Analog SSG** — static HTML output, fast page loads, SEO-friendly
- **Markdown content** — same familiar writing experience via `@analogjs/content`

## What's new?

- The **Blog** page now shows both local markdown posts and summaries from my [Medium feed](https://medium.com/@hantsy)
- The **Tutorials** section replaces the old publications page
- **Service offerings** are now integrated into the home page
- **Dark mode** support is built in
